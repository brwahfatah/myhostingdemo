Dashboard Tour

Welcome to your Hosting Dashboard! This guide will help you navigate the main sections and make the most of your hosting experience.

Dashboard Overview

Upon logging in, you’ll see:

  • Account Summary: View your current plan, active domains, and usage statistics.
  • Quick Actions: Easily create a website, manage domains, or contact support.
  • Notifications: Stay informed with important updates and alerts.

Navigation Menu

Located on the left, the menu includes:

  • Home: Return to the main dashboard.
  • Services: Manage hosting plans and servers.
  • Domains: Register new domains or manage existing ones.
  • Billing: View invoices and payment history.
  • Support: Submit tickets or reach out for help.

Key Features

Creating a Website

  1. Click Create Website in Quick Actions.
  2. Select your hosting plan.
  3. Choose an existing domain or register a new one.
  4. Follow the setup wizard to complete the process.

Managing VPS

  1. Go to Services → VPS Hosting.
  2. Select your VPS instance.
  3. Use the Console for server management.
  4. Perform actions like rebooting, taking snapshots, or configuring your VPS.

Monitoring Usage

  • Track CPU, RAM, and Disk usage for each server.
  • Set up alerts to notify you when resource limits are approached.

Tips

  • Explore: Take time to click through each section to discover all available features.
  • Support: If you need assistance, the Support section is always available.
  • Security: Regularly update your password and review account activity for added security.
